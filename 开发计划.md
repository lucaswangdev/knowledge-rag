  5. 处理流程                                                                                                       
                                                                                                                    
  同步处理（简单实现）                                                                                              
                                                                                                                    
  1. 接收文件上传 → 2. 验证文件类型/大小 → 3. 保存到临时位置 → 4. 提取文本 → 5. 创建文档记录 → 6. 向量化分块 → 7.   
  返回结果                                                                                                          
                                                                                                                    
  异步处理（生产环境推荐）                                                                                          
                                                                                                                    
  1. 接收文件上传 → 2. 保存文件并创建pending状态记录 → 3. 返回任务ID → 4. 后台任务处理 → 5. 用户轮询或Webhook通知   
                                                                                                                    
  6. 安全考虑                                                                                                       
                                                                                                                    
  1. 文件类型验证：基于MIME类型和扩展名双重验证                                                                     
  2. 大小限制：防止大文件攻击                                                                                       
  3. 病毒扫描：可集成ClamAV等扫描工具                                                                               
  4. 路径安全：防止目录遍历攻击                                                                                     
  5. 访问控制：文件访问权限验证
